### What the echo fix does (so you remember the design)
On speakers, the mic re-hears the far side, so Whisper transcribes the same words
twice (clean on SYS, garbled on MIC). The engine now **holds new MIC ~1s** for live
chronological order and publishes everything, **no live de-dup**. All echo removal is a
single end-of-session cleanup over the saved transcript (`dedup.strip_mic_echoes`), which
is order-independent and has full context, so it can never lose real speech to a bad live
match. Anchor-prompt leak ("Ons praat Suid-Afrikaans, nie Nederlands nie") is filtered,
scoped to the full phrase only. Tests: `tests/test_dedup.py` (9) + updated
`tests/test_engine_drain.py`. All green.
Known limit: a mic echo that straddles two SYS chunks can still survive. Headphones are
the clean fix (documented in the Quick Start guides + the in-app pre-meeting tip).

### The deliverable

### What the redesign added (vs the old bland page)
- **Product is the hero:** two-column hero with a live transcript panel (forked from the app's
  own live screen) showing a code-switched Afrikaans/English meeting, Offline lock, mic/system
  meters, live caret.
- **IBM Plex** typography (Sans body + headings now, Mono for timestamps/paths).
- **Three palettes** (Clinical / Warm Paper / Veld) + a **real dark-mode toggle**, all persisted
  to localStorage.
- Numbered sections, hairline card grid, "leave the cloud behind" checklist, **Open Graph +
  JSON-LD SoftwareApplication**.

### Decisions made (and why)
1. **Self-hosted the fonts, base64-embedded** (latin subset, 7 weights actually used). The design
   loaded IBM Plex from Google Fonts; that makes a privacy product's page phone Google on every
   visit. Embedding keeps it offline + private. Cost: 23 KB -> 323 KB. Worth it.
2. **Dropped the React/Babel "Tweaks" panel** (design-time review scaffolding, not product). The
   logo/palette/font setters survive in the inlined JS (`window.VM`), so changing a default is a
   one-liner.
3. **Single self-contained file** (matches "downloadable" + the offline promise).
4. **Stripped em-dashes from code comments** too (house rule).

### Locked-in defaults (Sean chose this session)
- **Headline font: Sans** (was Serif). Set in the `<html data-hfont="sans">` attribute + the JS
  fallback. The `html[data-hfont="serif"]` CSS path is intact, so flipping back works.
- **Palette: Clinical Quiet** (unchanged default).
- **Logo: speaker placeholder.** Sean is having **Chenelle build a custom logo**, will confirm.

### How to rebuild the landing page (e.g. after the logo lands)
Source + build scripts are preserved in OneDrive so this is reproducible on the laptop:
- **Design source bundle:** `landing/design-bundle/` (README, chat transcript, multi-file HTML,
  `vm-tokens.css`, `landing.js`, screenshots).
- **Build scripts:** `landing/build/` -> `fetch_fonts.py`, `assemble.py`, `validate.py`,
  `_fontface.css` (the base64 fonts, so you do NOT need to re-fetch from Google).
- **Pipeline:** `assemble.py` reads the design bundle + `_fontface.css`, strips the Google Fonts
  import, inlines fonts + tokens + cleaned JS, drops the Tweaks panel, sets the locked defaults
  (Sans/clinical/speaker), strips dashes, writes `Volksmond - Landing Page.html`. Then
  `validate.py` checks: no external calls, 7 fonts, EN/AF parity (52/52), no dashes, structure.
- The copied scripts use paths relative to their own location, so `python assemble.py` from
  `landing/build/` should just work. If a path complains, point `BUNDLE` at
  `landing/design-bundle/project` and keep `_fontface.css` beside the script.
- Validation last passed: ALL CHECKS PASS (321 KB, 7 faces, urls = digiphyte.com + schema.org,
