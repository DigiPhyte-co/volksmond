# Volksmond brand mark

The Volksmond logo: a friendly "listening face" — five waveform bars (the levels
/ eyes) above a smile curve. Real asset, do not redraw. Source: Chenelle, 2026-06-04.

## Files (same mark, four colourways)

| File | Colour | Use on |
|---|---|---|
| `volksmond-mark-black.{svg,png}` | `#000000` | light backgrounds, print |
| `volksmond-mark-white.{svg,png}` | `#ffffff` | dark backgrounds, the app icon tile |
| `volksmond-mark-blue.{svg,png}` | `#36587b` (Clinical accent) | the brand default on light |
| `volksmond-mark-lightblue.{svg,png}` | `#7ac1f2` (Trustworthy) | accent / dark backgrounds |

PNGs are high-resolution transparent renders. SVGs are vector (viewBox 0 0 1500 1500).

## How it ships in the product

Most surfaces use an inline `currentColor` version of this exact geometry, so the
mark inherits the active palette and adapts to light/dark automatically (brand blue
on light, light-blue on dark), the same way the old mark did. That inline form lives
in:

- `live_transcribe/web/static/app.js` -> `markSvg()` (the in-app wordmark)
- `Volksmond - Landing Page.html` (built from `landing/build/assemble.py`, which holds
  the canonical inline string; rebuild after any change)
- `docs/volksmond-quick-start*.html` (the Quick Start guide header; regenerate the PDFs after editing)

Fixed-colour uses:

- `live_transcribe/web/static/favicon.svg` — brand blue `#36587b`
- `volksmond.ico` (app / taskbar icon) — white mark on a brand-blue rounded tile,
  generated by `build-icon.py` from `brand/volksmond-mark-white.png`

Fast Track colourway, worn by the direct-download edition so it is distinguishable from a
Microsoft Store install of the same app on the same machine. Same geometry, same corner
radius, same padding, colours swapped:

- `volksmond-fasttrack.ico`: brand-blue mark on a WHITE rounded tile, generated by
  `build-icon.py` from `brand/volksmond-mark-blue.png`
- `live_transcribe/web/static/favicon-fasttrack.svg`: the favicon.svg artwork, unedited,
  on that same white tile; also written by `build-icon.py`

After changing the mark: rerun `python build-icon.py`, rebuild the landing page via
`landing/build/assemble.py`, regenerate the Quick Start PDFs, and rebuild the exe
(`build-app.ps1`) so the new icon + UI mark ship.
